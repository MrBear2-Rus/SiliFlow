**三个硬限制（本次升级要动的根）**

1. **信号只有 1 位**。`Pin` 没有位宽字段，`Wire::width` 是*描边粗细*不是位宽。
2. **没有子电路**。`Project` 有多图纸，但图纸不能被例化；`tunnel` 只能做同图网络别名。
3. **没有剪贴板**。剪切/复制/粘贴是菜单占位（`MainFrame.cpp:869-871` 绑到 `OnEditNotImplemented`）。

## 3. 两个地基级决策（必须先拍板）

### 3.1 总线（多位信号）

**为什么绕不开**：ALU、寄存器、计数器、RAM、Verilog 的 `[7:0]`、VCD 的多位值块——全都建立在多位总线上。只支持 1 位，这个工具就只能做门级教学演示。而且它影响**数据格式、求值引擎、渲染、真值表、Verilog、VCD 全部**，做晚了所有下游功能都要返工。

| 方案 | 做法 | 代价 | 结论 |
| --- | --- | --- | --- |
| **A 真总线** | `Pin`/`Wire` 带位宽，值是位向量；splitter 做真位选/拼接 | 数据格式 v2 + 全链路改造 | ✅ **推荐** |
| B 假总线 | 元件内部按多位算，对外还是 1 位引脚 | 便宜，但 Verilog/VCD/位选全废 | 只适合应急 |
| C 不做 | 永远 1 位 | — | 等于放弃 EDA 定位 |

**建议**：走 A，但**位宽设上限 32 位**（够画 ALU / 寄存器堆）。`LogicSignal` 从单值升级成 `LogicVector`（每位仍是四值），旧接口保留 1 位重载以减少改动面。

**顺带必须做的重命名**：`Wire::width`（描边粗细）改叫 `strokeWidth`，把 `width` 让给位宽。这是纯机械改名，但漏一处就是 bug，要做一次全量核对。

### 3.2 子电路（层次设计）

**为什么绕不开**：真实工程画不在一张图上；更重要的是 **Verilog 的 module ↔ 子电路天然对应**，没有它，M4「码 → 图」只能展开成一张平铺大图，导回来就没法跟原图对上。

| 方案 | 做法 | 代价 | 结论 |
| --- | --- | --- | --- |
| **A 图纸即模块** | `CircuitSheet` 升级为可例化的 `SheetDef`；例化 = 一个 `kind=subcircuit` 的元件 | 顺着现有 `Project` 多图纸走，成本最低 | ✅ **推荐** |
| B 独立元件库 | 另建用户元件库 + 端口映射表 | 与 Project 结构重复，两套概念 | 不推荐 |

**要点**：
- 例化元件 = 「图纸引用 + 端口映射 + 位置/旋转」
- 求值要**层次展开**，并缓存每个实例的内部状态（不能把子图平铺进父图，否则实例无法各自持有寄存器状态）
- 防递归：A 例化 B、B 例化 A 要能检出并拒绝
- 这推翻了 v3.0 第 2 章「子电路本期不做」的决策，**要显式改掉**

## 5. 架构影响

| 层 | 变化 |
| --- | --- |
| `core/` | 新增位向量类型与位宽；`Pin`/`Wire` 加字段；`CircuitSheet` → 支持例化；数据格式 v2 + 迁移器 |
| `core/sim/` | 值从标量变向量；求值按位；层次展开 + 每实例状态；增量重建 |

| `panels/` | 属性面板支持位宽编辑；新增真值表面板；波形面板落地 |

**不变量继续成立**（不能破）：
- 依赖只能向下；L3 之间不横向依赖，跨模块走 `core::Services`
- 运行时状态（仿真值）绝不写回 `ComponentInstance` / `Wire`
- 翻转电平、单步 tick 不进撤销栈
- 视觉尺寸只从 `ui::` 令牌取

## 6. 实施批次

### U0 地基：总线 + 数据格式 v2　✅ 已完成（2026-10-19）
- A1/A2/A3 + `splitter` 真位选 + 全量迁移 + 自检扩充
- **验收**：旧 `.sfproj` 能打开且渲染一致；4 位加法器能画能跑；自检含 1 位与 4 位两组用例
- **依赖**：无。**这一批不做，U2/U3/U4 全部要返工**

### U1 手感包：让编辑不再难受
- E1/E3/E4/E5 + F1 + F2
- **验收**：框选 5 个元件 → Ctrl+C/Ctrl+V 粘贴到空白处，id 重编、坐标偏移、撤销一步；对齐后间距均匀；关掉程序再开能恢复未保存内容
- **依赖**：无（可与 U0 并行，建议 U0 之后做，因为粘贴要复制位宽字段）

### U2 仿真闭环：时序 + 元件库
- C1 + B1/B2/B3/B4 + C2 录波 + C6 增量重建
- **验收**：`clock → 4 位计数器 → 七段数码管` 单步跑起来数字递增；探针录一段波形能存成 `.vcd`
- **依赖**：U0（多位）

### U3 设计输入输出：Verilog + VCD
- D1 + D2 + D3 + B7 子电路
- **验收**：4 位计数器导出 `.v`，`iverilog -tnull` 通过；删空后导回来元件数/连接一致、布局不重叠；子电路能例化两层
- **依赖**：U0 + U2（要有寄存器语义才谈得上 `always`）

### U4 分析与综合
- C3 真值表 + D4 综合 + D5/D6 导出图
- **验收**：4 位全加器真值表 256 行正确（或按位拆成 1 位）；真值表生成的门级电路可再导出 Verilog
- **依赖**：U0 + U3（复用导入器落地）

### U5 打磨
- F3 性能 + F4 暗色 + F5 快捷键 + F6 i18n + E6/E7 + C4/C5 + B6 存储件
- **依赖**：前四批

**总量估计**：U0~U4 是主体，代码量预计从 1.4 万行涨到 **2.5~3 万行**。U5 是长期打磨，可以持续做。

## 7. 主要风险

| # | 风险 | 应对 |
| --- | --- | --- |
| R1 | **总线改造波及面太大**，改一半会得到既不能编译也不能运行的半成品 | 单独占一个批次，先做「1 位等价 + 位宽字段」，确认自检 51 项仍然全过，再开多位功能 |
| R2 | 数据格式 v1/v2 混用导致旧工程打不开 | 迁移器 + 保留 v1 读入路径；自检里放一个 v1 样例文件 |
| R3 | 子电路求值层次展开后状态互相串（两个实例共享寄存器） | 每个实例独立 `SimState` 槽位；自检里放「同一个子电路例化两次，各自计数」 |
| R4 | 子电路递归例化导致展开死循环 | 例化时做引用栈检测，检出即拒绝并报路径 |
| R5 | 多位真值表组合爆炸 | 输入总位宽上限（比如 12 位），超限拒绝并提示 |
| R6 | Verilog 导入的布局器做成第二个「自动布局」项目，无限膨胀 | 明确只吃子集 + 固定两档布局；不支持的语法给行号报错而不是猜 |
| R7 | 一次改太多，回归无法定位 | 每批结束必须：全量重编 0 告警 + 自检全过 + GUI 冒烟；批次之间不并行改同一模块 |
